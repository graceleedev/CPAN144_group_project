# BistroTable – Restaurant Reservation Web Application

## Project Overview
BistroTable is an interactive web application that allows users to browse restaurants, make reservations, and check reviews. 

## Features
- Browse restaurants with detailed information
- Make reservations through an reservation flow
- Check restaurant reviews

## Technologies
- Frontend: React, Next.js, HTML, CSS
- APIs: REST API for restaurant review data
- Tools: GitHub for version control and team collaboration

## Installation & Setup
1. Clone the repository: `git clone https://github.com/graceleedev/CPAN144_group_project.git`
2. Navigate to the project directory: `cd restaurant-reservation-app`
3. Install dependencies: `npm install`
4. Run the development server: `npm run dev`
5. Open http://localhost:3000 in your browser to view the app.
